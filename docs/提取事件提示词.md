# 提示词：从教材章节提取历史事件（结构化 JSON）

> 版本：v1.1（2026-08-01）/ v1.2（2026-08-01 战国试点后修订）/ v1.3（2026-08-01 坐标方案）
> 用途：批量从教材章节文本提取可考历史事件，产出符合需求文档 §3.1（17 字段）的 JSON 数组，作为正式版 data.js 数据源
> v1.1 修订：迁都筛选规则细化（战略迁都收）；title/dynasty/wikiSlug 规范补充；新增常见错误样例（2026-08-01 试验数据提炼）
> v1.2 修订（战国试点验证后）：① 年份**以朱绍侯教材为准**，纠正原错误样例"秦灭巴蜀=-318 错"的误导；② 补覆盖密度、过程/趋势类事件、关联战役合并三条筛选规则；③ title 规范澄清"复合专名允许、禁描述句"；④ yearMode 判定补教材优先级
> v1.3 修订：location 规则——先秦事件必须写"具体地点（今址）"，禁止只写国名（CHGIS 覆盖 -222~1911、先秦零覆盖已实测，坐标需按今址解析）
> 配套：低成本 LLM API + JSON mode（DeepSeek / Qwen-turbo 等，`response_format={'type':'json_object'}`）
> 前置：需求文档 v1.3 · 正式版开工文档 §2

## 一、提示词正文（直接复制给模型）

```
你是考研历史学统考（313，中国史+世界史并重）的命题分析员，熟读朱绍侯《中国古代史》等统考教材。
任务：从下面提供的教材章节文本中，提取【可考的历史事件】，输出为严格的 JSON 数组。

# 输出要求
- 只输出一个 JSON 数组，不要任何解释、不要 Markdown 代码块包裹、不要额外文字。
- 每条事件一个 JSON 对象，字段与类型见下方 Schema，全部字段必填（无内容用 "" 或 []）。
- 公元前年份一律用负数（如 前632年 → -632）。
- 按时间先后排序输出。

# Schema（17 字段）
{
  "title": string,        // 事件名（标准中文名，干净简洁：不带括号注释——"邯郸之战"而非"邯郸之战（窃符救赵）"；不用描述句——"武卒制"而非"吴起在魏国创制武卒制"；注释/别名进 examTip 或 tags；复合专名如"胡服骑射""围魏救赵""长平之战"是标准名允许，禁的是把事件经过写成 title 的描述句）
  "year": int|null,       // 年份（公元前为负数）；era 模式为 null；range 模式填起始年
  "yearMode": string,     // "exact" | "approx" | "era" | "range"
  "yearRange": [int,int]|null,  // 仅 range 模式必填，如 [-551,-479]
  "dynasty": string,      // 朝代名（如 春秋、西汉、唐）——只写朝代，不要混入国别（"战国（魏）"→"战国"，国别信息进 tags）
  "period": string,       // 大分期，枚举：先秦/秦汉/魏晋南北朝/隋唐/宋元/明清
  "type": string,         // 枚举：政治/军事/经济/文化/制度
  "importance": int,      // 3=核心考点 2=常考 1=了解（判定规则见下）
  "summary": string,      // 教材学术腔，答题口径，2-3 句，可直接背诵
  "cause": string,        // 前因，一句话（无则 ""）
  "effect": string,       // 后果，一句话（无则 ""）
  "examTip": string,      // 口语复习腔，易错点/记忆钩子/连线提醒（无则 ""）
  "people": string[],     // 相关人物
  "location": string,     // 地点：写"具体地点（今址）"，如"桂陵（今山东荷泽）""大梁（今河南开封）"——坐标按今址解析；**禁止只写国名/区域（魏国/中原/列国）**（CHGIS 覆盖 -222~1911、先秦零覆盖，国名无法定位）；仅国别的事件留 ""（地图不标点，可在 examTip 注明）
  "tags": string[],       // 轻量标签，2-3 个
  "related": string[],    // 关联事件名（其他事件的标准 title，无则 []）
  "wikiSlug": string      // 暂填与 title 一致的事件名；无对应条目留 ""
}

# yearMode 判定规则
- exact：正文有明确年份（如"前632年""627年"）
- approx：正文用"约/大概/前后"等模糊词（如"约前1600年"）
- era：只有时代段、无具体年份（如"夏代中期""春秋时期"）——year 填 null，不写死精确年
- range：起止区间（人物生卒年、持续多年的过程），yearRange 填 [起,止]，year 填起始年
- **年份以朱绍侯教材为准**：教材写"前318年"就填 -318，即使市面常见纪年不同（如秦灭巴蜀市面常作前316）也以教材为准，并在 summary 注明"市面常作前316，313以教材为准"；禁止凭常见纪年改教材年

# 事件筛选标准（宁缺毋滥）
- 只收 313 可考事件：战役、会盟、变法、制度确立、重大文化现象、王朝更替等
- 不收：国君即位/卒年、细碎年份、教材一句话带过且非考点的内容
- 迁都：**看战略意义，构成考点就收**——政权存续/战略重心转移的标志（如周平王东迁、魏惠王迁都大梁、北魏孝文帝迁都洛阳）教材单列段落、必考；仅无考点意义的琐碎迁都不收
- era 类事件（文化遗址、时代现象）只有具备考点意义才收
- 覆盖密度：逐章通读，凡教材单列段落/明确叙述的【战役、会盟、变法、制度、政策、重大工程、重要思想人物、文化现象、王朝更替、战略迁都】都应提取，不漏考点；单章通常 15–40 条，密度大的章（如战国、秦汉）可到 50+，宁多勿漏（人工校时可删）
- 过程/趋势类事件（如"百家争鸣""中央集权制度确立"）：可收，用 era 模式，summary 首句点明其为"过程/趋势"而非单点事件；people 可空
- 关联战役合并规则：同一因果链、紧邻年份、教材合并叙述的连战（如丹阳之战与蓝田之战同属前312秦楚之战），合成一条（title 取惯用合称如"秦楚丹阳蓝田之战"）；年份不同或教材分述的（如桂陵、马陵）则分条

# importance 判定
- 3：教材以独立小节/专题讲述，或近年 313 真题设问过
- 2：教材以独立段落讲述、构成考点但未单列小节
- 1：教材正文顺带提及，仅作背景
- 拿不准降一档

# 文案腔调（两层分工，避免单一腔调）
- summary/cause/effect：教材学术腔——客观、凝练、答题可直接用
- examTip：口语复习腔——犀利、抓易错点（"别与崤之战颠倒""连线题最爱"），像学长划重点，不是教科书语言

# 章节文本
<<<<< 在此粘贴教材章节全文 >>>>>>
```

## 二、使用说明（给操作者）

### 2.1 模型与参数建议

| 项 | 建议 |
|----|------|
| 模型 | DeepSeek（deepseek-chat）/ Qwen（qwen-turbo 或 plus）等低价档 |
| JSON 保证 | `response_format={'type':'json_object'}`（JSON mode），提示词要求是底线，参数保证是保险 |
| 温度 | 0.2（低随机，保证稳定输出） |
| 输入 | 单章文本一次提交（控制单次输出条数 30-60 条，避免截断） |

### 2.2 输出校验（代码层，不可省）

1. **JSON 解析**：`json.loads`（注意历史文本常见的非法控制字符，用 `strict=False` 或清洗 `\u0000-\u0008` 等）
2. **schema 校验**：17 字段齐全、`yearMode` 枚举合法、`yearRange` 与 mode 匹配（range 必填、其他为 null）、`period`/`type` 在枚举内
3. **年份正则核对**：抽取正文中所有 `[前]?\d+年` 模式，交叉核对 LLM 输出的 `year`——LLM 编年份的错误靠正则抓
4. 失败处理：解析失败或校验不过 → 原样重试（最多 3 次）；仍失败 → 标记人工处理

### 2.3 人工校对（成本大头，不可省）

- 年份正确性（尤其夏商周断代口径：教材 vs 断代工程差异，era 段不得写死精确年）
- importance 星级漂移（对照 §3.2 标准逐条过）
- 文案腔调：学术腔是否够"答题"、examTip 是否够"犀利"
- related 是否指向真实存在的其他事件 title

### 2.4 few-shot 质量基准

打样数据（demo.html / demo2.html 内嵌 33 条）是现成的高质量样本：年份准确、两层腔调到位、考点钩子犀利。批量提取前，建议先从打样数据抽 3 条（era/exact/range 各一）作为提示词的示例对照。

### 2.5 常见错误样例（2026-08-01 试验数据提炼，防复发）

| 错误类型 | 实例 | 修正 |
|---------|------|------|
| 年份以教材为准 | 秦灭巴蜀：朱绍侯教材系于前318年（与五国伐秦同年不同事），市面常作前316 | 以教材年份 -318 为准，summary 注明"市面常作前316，313以教材为准"；同年不同事须逐条对照原文，禁止凭印象填年或强行错开 |
| title 带括号注释 | "邯郸之战（窃符救赵）" | title 用干净事件名，括号内容移 examTip/tags |
| title 用描述句 | "吴起在魏国创制武卒制" | 改"武卒制" |
| dynasty 混入国别 | "战国（魏）" | 只写"战国"，国别进 tags |
| era 可用精确年 | "田单复国"（教材前279）、"阏与之战"（前270）标了 era/range | 教材有明确年份时用 exact（战国史料年份明确，era 占比不应过高） |
| summary 与 year 不一致 | 桂陵之战 year=-353、summary 先述"前354围邯郸" | year 取事件本体发生年（-353），summary 可含前奏年份但表述要能对上 |
