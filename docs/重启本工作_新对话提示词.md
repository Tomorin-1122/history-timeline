## 四、17 字段 Schema（每条事件必填，无内容用 "" 或 []）
- title: string — 事件标准中文名，干净简洁，禁括号注释 / 描述句
- year: int|null — 公元前用负数（前632 → -632）；era 模式为 null；range 模式填起始年
- yearMode: string — "exact" | "approx" | "era" | "range"
- yearRange: [int,int]|null — 仅 range 必填
- dynasty: string — 只写朝代（如 春秋 / 西汉 / 元），国别进 tags
- period: string — 枚举：先秦 / 秦汉 / 魏晋南北朝 / 隋唐 / 宋元 / 明清
- type: string — 枚举：政治 / 军事 / 经济 / 文化 / 制度
- importance: int — 3=核心考点 2=常考 1=了解
- summary: string — 教材学术腔，2–3 句，答题可直接背
- cause: string — 前因一句（无则 ""）
- effect: string — 后果一句（无则 ""）
- examTip: string — 口语复习腔，易错点 / 记忆钩子（无则 ""）
- people: string[] — 相关人物
- location: string — **「具体地点（今址）」**（如「桂陵（今山东菏泽）」）；仅国别 / 区域事件留 ""（禁写国名 / 区域）
- tags: string[] — 轻量标签 2–3 个
- related: string[] — 关联事件名（必须指向其他事件的真实 title，无则 []）
- wikiSlug: string — 暂填与 title 一致；无对应条目留 ""

## 五、提取提示词正文（复制下面全部内容，含首尾 ``` 给模型）

```
你是考研历史学统考（313，中国史+世界史并重）的命题分析员，熟读朱绍侯《中国古代史》等统考教材。
任务：从下面提供的教材章节文本中，提取【可考的历史事件】，输出为严格的 JSON 数组。

# 输出要求
- 只输出一个 JSON 数组，不要任何解释、不要 Markdown 代码块包裹、不要额外文字。
- 每条事件一个 JSON 对象，字段与类型见下方 Schema，全部字段必填（无内容用 "" 或 []）。
- 公元前年份一律用负数（如 前632年 → -632）。
- 按时间先后排序输出。

# Schema（17 字段）
{
  "title": string,        // 事件名（标准中文名，干净简洁：不带括号注释——"邯郸之战"而非"邯郸之战（窃符救赵）"；不用描述句——"武卒制"而非"吴起在魏国创制武卒制"；注释/别名进 examTip 或 tags；复合专名如"胡服骑射""围魏救赵""长平之战"是标准名允许，禁的是把事件经过写成 title 的描述句）
  "year": int|null,       // 年份（公元前为负数）；era 模式为 null；range 模式填起始年
  "yearMode": string,     // "exact" | "approx" | "era" | "range"
  "yearRange": [int,int]|null,  // 仅 range 模式必填，如 [-551,-479]
  "dynasty": string,      // 朝代名（如 春秋、西汉、唐）——只写朝代，不要混入国别（"战国（魏）"→"战国"，国别信息进 tags）
  "period": string,       // 大分期，枚举：先秦/秦汉/魏晋南北朝/隋唐/宋元/明清
  "type": string,         // 枚举：政治/军事/经济/文化/制度
  "importance": int,      // 3=核心考点 2=常考 1=了解（判定规则见下）
  "summary": string,      // 教材学术腔，答题口径，2-3 句，可直接背诵
  "cause": string,        // 前因，一句话（无则 ""）
  "effect": string,       // 后果，一句话（无则 ""）
  "examTip": string,      // 口语复习腔，易错点/记忆钩子/连线提醒（无则 ""）
  "people": string[],     // 相关人物
  "location": string,     // 地点：写"具体地点（今址）"，如"桂陵（今山东荷泽）""大梁（今河南开封）"——坐标按今址解析；**禁止只写国名/区域（魏国/中原/列国）**（CHGIS 覆盖 -222~1911、先秦零覆盖，国名无法定位）；仅国别的事件留 ""（地图不标点，可在 examTip 注明）
  "tags": string[],       // 轻量标签，2-3 个
  "related": string[],    // 关联事件名（其他事件的标准 title，无则 []）
  "wikiSlug": string      // 暂填与 title 一致的事件名；无对应条目留 ""
}

# yearMode 判定规则
- exact：正文有明确年份（如"前632年""627年"）
- approx：正文用"约/大概/前后"等模糊词（如"约前1600年"）
- era：只有时代段、无具体年份（如"夏代中期""春秋时期"）——year 填 null，不写死精确年
- range：起止区间（人物生卒年、持续多年的过程），yearRange 填 [起,止]，year 填起始年
- **年份以朱绍侯教材为准**：教材写"前318年"就填 -318，即使市面常见纪年不同（如秦灭巴蜀市面常作前316）也以教材为准，并在 summary 注明"市面常作前316，313以教材为准"；禁止凭常见纪年改教材年

# 事件筛选标准（宁缺毋滥）
- 只收 313 可考事件：战役、会盟、变法、制度确立、重大文化现象、王朝更替等
- 不收：国君即位/卒年、细碎年份、教材一句话带过且非考点的内容
- 迁都：**看战略意义，构成考点就收**——政权存续/战略重心转移的标志（如周平王东迁、魏惠王迁都大梁、北魏孝文帝迁都洛阳）教材单列段落、必考；仅无考点意义的琐碎迁都不收
- era 类事件（文化遗址、时代现象）只有具备考点意义才收
- 覆盖密度：逐章通读，凡教材单列段落/明确叙述的【战役、会盟、变法、制度、政策、重大工程、重要思想人物、文化现象、王朝更替、战略迁都】都应提取，不漏考点；单章通常 15–40 条，密度大的章（如战国、秦汉）可到 50+，宁多勿漏（人工校时可删）
- 过程/趋势类事件（如"百家争鸣""中央集权制度确立"）：可收，用 era 模式，summary 首句点明其为"过程/趋势"而非单点事件；people 可空
- 关联战役合并规则：同一因果链、紧邻年份、教材合并叙述的连战（如丹阳之战与蓝田之战同属前312秦楚之战），合成一条（title 取惯用合称如"秦楚丹阳蓝田之战"）；年份不同或教材分述的（如桂陵、马陵）则分条

## 六、合并校验脚本（每章把分块 JSON 合并 + 清洗 + schema 校验）
把大模型按块输出的 `_xxx_p1.json`…`_xxx_pK.json` 合并成一个 `第NN章_pilot_YYYYMMDD.json`。脚本用 Write 工具写成 ASCII 文件再跑（**别用 Git Bash heredoc 写长脚本，会截断**）。

```python
import json, glob, re, sys

def blk_num(f):
    m = re.search(r'_p(\d+)\.json', f)
    return int(m.group(1)) if m else 0

blocks = sorted(glob.glob('_*_p*.json'), key=blk_num)
all_items = []
for f in blocks:
    txt = open(f, encoding='utf-8').read()
    txt = txt.replace('ëxamTip', '"examTip"')   # 修分块写 JSON 偶发的 key 损坏（缺字母 e）
    data = json.loads(txt)
    all_items.extend(data)

REQ = ['title','year','yearMode','yearRange','dynasty','period','type','importance',
       'summary','cause','effect','examTip','people','location','tags','related','wikiSlug']
errs = []
for i, it in enumerate(all_items):
    keys = set(it.keys())
    if missing := [k for k in REQ if k not in keys]:
        errs.append('[%d] %s MISSING %s' % (i, it.get('title'), missing))
    if extra := [k for k in keys if k not in REQ]:
        errs.append('[%d] %s EXTRA %s' % (i, it.get('title'), extra))
    ym = it.get('yearMode')
    if ym not in ('exact','approx','era','range'):
        errs.append('[%d] %s bad yearMode %s' % (i, it.get('title'), ym))
    if ym == 'exact' and not isinstance(it.get('year'), int):
        errs.append('[%d] %s exact needs int year' % (i, it.get('title')))
    if ym == 'range' and not isinstance(it.get('yearRange'), list):
        errs.append('[%d] %s range needs yearRange' % (i, it.get('title')))
    if ym == 'era' and it.get('year') is not None:
        errs.append('[%d] %s era year should be null' % (i, it.get('title')))
    if it.get('wikiSlug') != it.get('title'):
        errs.append('[%d] %s wikiSlug!=title' % (i, it.get('title')))
    if not isinstance(it.get('related'), list):
        errs.append('[%d] %s related not list' % (i, it.get('title')))

print('TOTAL', len(all_items))
if errs:
    print('ERRORS', len(errs))
    for e in errs: print(' -', e)
    sys.exit(1)
else:
    out = sys.argv[1] if len(sys.argv) > 1 else 'merged_pilot.json'
    json.dump(all_items, open(out, 'w', encoding='utf-8'), ensure_ascii=False, indent=2)
    print('WROTE', out)
```

跑法：`python3 _merge.py 第02章_pilot_20260802.json`

## 七、已知坑（重蹈过，必看）
- 🔴 **Git Bash heredoc 超 ~3KB 被截断 / 篡改**（3.6–4.4KB 报 `unexpected EOF` 且行号漂移）。→ 写 Python 脚本一律用 **Write 工具（纯 ASCII）**；写中文大文件用 Bash heredoc 分块 `cat >>` 每块 ≤2.5KB。
- 🔴 **分块写 JSON 偶发 key 损坏 `ëxamTip`（缺字母 "e"）**。→ 合并脚本第一句做字面替换 `txt.replace('ëxamTip', '"examTip"')`；别靠正则（`\S` 匹配异常会漏修）。
- 🔴 **临时分块清理**：项目内本会话产物（`_xxx_pK.json`、合并脚本）用 `python3 -c "import os;os.remove(p)"` 直接删；回收站删除包装会把项目绝对路径识别成相对路径而 fail-closed（文件不删），别被它骗。
- 🟡 **合并脚本按块号数字排序**：glob 字典序会排成 p1,p10,p11,p2… 导致先解析 p10 报错；用 `key=blk_num` 数字排序。
- 🟡 **location 铁律**：有具体发生地 →「古地名（今今址）」；仅国别 / 区域（变法、制度、思想潮流、统一战争）→ location 留 ""，可在 examTip 注明国别；**禁止把国名 / 区域当 location**（CHGIS 覆盖 -222~1911，先秦零覆盖，国名无法定位）。
