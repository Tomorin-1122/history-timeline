## 二、技术栈与架构（已落地）

### 2.1 关键技术约束：file:// 下不能用 fetch 与 ES module
双击即开（需求文档 §6）延续，**file:// 下 fetch() 和 `<script type="module">` 均被 CORS 拦截**：
- ✅ `data.js` 以全局变量注入（`const EVENTS/CHAPTERS/COORDS`），普通 `<script>` 按序加载
- ✅ 逻辑代码拆普通 script（无 ES module），命名空间隔离

## 三、数据管线（维护/补录用）

### 3.1 生产流程（新增事件时复用）
```
① LLM 提取（分块 _xxx_pK.json，提示词见 提取事件提示词.md）
② scripts/merge_blocks.py 合并 + 清洗（修 ëxamTip）+ schema 校验
③ js/gen_data.js 的 PILOTS 加行（如新章）→ node js/gen_data.js
④ node js/check_data.js（数据关卡，0 错误才过）
⑤ 浏览器验收（tests/）→ git commit
```

### 3.2 事件 Schema（20 字段）
`title / year / month / yearMode / yearRange / era / eraSub / dynasty / period / type / importance / summary / cause / effect / examTip / people / location / tags / related / wikiSlug`

- `type` 枚举 7 类：政治/军事/经济/文化/制度/**民族关系/对外关系**（纯外国内政不收）
- `yearMode`：exact/approx/era/range；**史前"距今X万年"一律 era 模式**（禁超大负年破坏比例）
- `month`：可选 1-12，同年事件按月份分先后（教材明确月份才填，如"前209年七月"→7；无则省略）——前端时间轴/地图播放/步进均按 month 二级排序，无 month 事件排在有 month 之后
- `location` 铁律：`具体地点（今址）`（如"长安（今陕西西安）"）；仅国别/区域留 ""
- `related` 必须指向全库存在的 title（check_data 拦悬空）

### 3.3 数据维护流程（修改已有事件）
本地起服务 `node server.js` → 页面右上「编辑」→ 改完自动写回 data/*.json → 重建 data.js。或直接改 data/*.json + 重跑 gen_data/check_data。

## 四、坐标体系（重点，坑多）

### 4.1 三级解析管道
```
CHGIS（古名+年份消歧，-222~1911） → 未命中 → 今址表 coords_modern.json 兜底 → 仍无 → 人工定坐标入 coords_resolved.json
```
- **CHGIS 同名消歧失败是系统性坑**（2026-08-03 审计发现 16 条）：宁远→湖南宁远县（应辽宁兴城）、嘉定→四川乐山（应上海嘉定）、西宁→广东（应青海西宁）、渤海→山东滨州（应黑龙江宁安）等
- **坐标入库必跑校验**：`node scripts/audit_coord_range.js`（省份范围校验，抓跨省错误）
- 大区域（幽云十六州/全国/云南贵州）与域外无精确点 → **留空不上地图**（取点反而误导）
- 范围型事件（多地点）→ 取代表点（靖难→南京、郑和→南京、戚继光→台州、万历援朝→平壤 等 12 条已定）

### 4.2 共享坐标处理（地图可点性）
- **≥10 条重合的城市**（长安/北京/南京/开封等）→ leaflet.markercluster 聚合，低 zoom 显示数字簇，簇色=占比最高门类色；**播放/步进/原始社会模式不聚合**（事件少直接显示）
- **<10 条重合** → 前端确定性 jitter（title 哈希 ±550m 散开，同一事件每次位置稳定），不聚类
- 参考：`js/map.js` 的 `HEAVY_SET / JITTER_SET / jitterCoord / iconCreateFunction`

### 4.3 坐标文件
- `data/coords_resolved.json`：title → [lat,lng]（CHGIS 命中 + 人工定）
- `data/coords_modern.json`：`"今XXX"` → [lat,lng]（location 括号今址兜底）

## 五、地图交互特性（已迭代完成）

- **双时间轴完全隔离**：原始社会（史前对数刻度，无聚类）/ 历史（-2070~1840）
- **同年按月份分先后**：`month` 字段（1-12，49 条已回填）；时间轴/地图播放/步进按 (year, month) 排序，步进同年在月份间聚焦（focusKey 加粗），同月事件视为同时——近代史同年密集事件更要用
- **连续播放 + keepN**：保留最近 N 个事件（10/5/3/2/1），旧渐透明、最新加粗置顶、到点才出现
- **倍速 6 档**（1×/2×/4×/8×/0.5×/0.1×，播放时细 step 防钳制）
- **步进 ◀▶**：精准翻事件（随章/门类/等第/搜索筛选联动）
- **分期筛选**：16 个分期链接按章过滤
- **聚类**：重灾组（≥10 条）成簇、簇色按门类、播放/步进/史前不聚
- **↑/↓ 章节跳转**：右下浮动，↑ 回当前章、↓ 跳下一章（时间轴视图）
- **全屏沉浸式**：⛶ 隐藏顶栏/页脚

## 七、经验教训沉淀（维护必读）

### 7.1 数据/坐标
1. **地点史实必须 web 验证**（梁犊起义=雍城非长安、河阴=孟津区非孟县）
2. **CHGIS 同名消歧不可信**：入库后跑 `audit_coord_range.js` 省份校验 + 抽核
3. **related 批量替换勿丢有效引用**（只替换悬空那一项）
4. **跨章重复事件只收一次**（related 改指保留者）
5. **type 枚举**：民族关系（境内）/对外关系（外国）；纯外国内政删除
6. **dynasty 禁带括号**（三国（魏）→曹魏、十六国（夏）→大夏）
7. **坐标质量红线**：大区域留空、\(0,0\) 校验、共享 jitter、古战场按遗址
8. **人工填坐标经度易错**（"今江西兴国"经度 105→115，差 10°）——人工坐标必复核

### 7.2 前端/交互
9. **HTML range step 钳制**：小数步长必须显式设 step
10. **marker 压盖=添加顺序**：最新置顶倒序添加
11. **三条路径要隔离**：显示/播放/步进都要加 ch===0 与筛选判断（改动一处要同步三处）
12. **聚类只用于重灾组**：全量聚类反而让 2-3 条事件也成簇（老板反馈）；播放/步进/史前不聚
13. **回归断言与行为耦合**：改行为同步改回归脚本
