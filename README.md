# 考研古代史时间轴

**把 313 要背的 2635 个考点，做成一张能点、能查、能自测的时间轴。**

线上版：<https://timeline.yinyizhuan.cn> · 对照视图：<https://timeline.yinyizhuan.cn/parallel/>

> 个人学习工具 · 内容由 AI 整理，不保证准确 · 一切以教材与考纲为准

教材的考点是散在书页里的。翻到第三遍，你还是记不住「黄册和鱼鳞图册谁管户口」。这个项目把朱绍侯、李侃/王桧林、吴于廑·齐世荣三套教材的事件拆成结构化条目，落到时间轴和地图上，配好前因后果与备考提示，可以按章看、按年筛、按图定位、按题自测。

## 五个视图

| 视图 | 用来做什么 |
|------|------------|
| **时间轴** | 按章分期浏览全部事件，点开看摘要、前因、后果与备考提示 |
| **地图** | 事件落到真实坐标，拖年份看考点在时空上怎么推进；清代疆域可叠省界 |
| **复习** | 翻牌自测、错题重练，含四种客观题型：判断题 / 选择题 / 排序题 / 多选题 |
| **关系** | 事件与人物织成力导图，看清一条因果链是怎么串起来的 |
| **对照** | 中外文明平行时间轴，同时期中外格局一眼对比 |

## 收录范围

| 史段 | 依教材 | 条数 | 时间跨度 |
|------|--------|------|----------|
| 中国古代史 | 朱绍侯《中国古代史》15 章 | 855 | 史前 ~ 1840 |
| 中国近现代史 | 李侃 / 王桧林 11 段 | 867 | 1838 ~ 2012 |
| 世界史 | 吴于廑·齐世荣六卷本 8 段 | 913 | 史前 ~ 2012 |
| **合计** | | **2635** | |

其中 2241 条带地图坐标，详情里嵌了 444 张历史插图。

每条事件除标题、年份、朝代外，还带这些字段：

- **summary** — 事件本身，两三句话说清
- **cause / effect** — 前因与后果，论述题的答题骨架
- **examTip** — 备考提示，哪个知识点容易混、往年怎么考
- **type** — 七分类：政治 / 军事 / 经济 / 文化 / 制度 / 民族关系 / 对外关系
- **importance** — 星级，用来筛重点、定复习优先级

## 快速开始

**线上**：直接打开 <https://timeline.yinyizhuan.cn>，无需安装，浏览器即用。

**本地**：clone 后双击 `index.html` 即可。无需安装、无需构建、无需起服务，此模式只读。依赖 jsdelivr 加载字体与 Leaflet，需联网。

**改数据**：双击 `启动.bat` 起本地服务（`http://localhost:3099`），点右上角「编辑」可增删改事件，保存自动写回 `data/*.json` 并重建 `js/data.js`。

## 数据从哪来

事件由 AI 按教材正文逐段提取，年份与归类经人工复核。取舍以 313 考纲为界：纯外国内政不收，只收与中国相关或考纲明确要求的部分。

历史疆域取自 CHGIS V6（复旦大学 / 哈佛燕京学社），经地图书知识库 CC0 转换。底图由天地图提供。

历史插图来自公开史料与网络，仅作教学辅助。

## 开发与维护

数据流是单向的：`data/*.json` → `node js/gen_data.js` → `js/data.js`。改完跑 `node js/check_data.js` 守质量关卡，`tests/` 下是 Playwright 验收脚本。

更细的交接文档、提取提示词与核验报告保留在本地 `docs/`，不随仓库发布。
